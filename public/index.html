Try this: Set auth-service to trace, then login. Watch the terminal — you'll see TRACE logs showing request parsing details that are normally invisible. Then set it back to info.
💡 Tip: Keep your terminal visible side-by-side. Watch for log_type field to identify log categories: access (server), event (domain), security (auth), database (MongoDB).
